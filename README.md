# PocketSmart AI

**PocketSmart AI: Your Smart Budget & Recommendation Assistant**

A simple responsive web application for tracking a monthly budget, recording expenses, and receiving smart spending recommendations.

## Features

- Set a monthly budget
- Add expenses by category
- Calculate total spending and remaining balance
- Smart rule-based spending recommendations
- Expense history
- Delete expenses
- Saves data in browser local storage
- Mobile-friendly interface

## Run

Open `index.html` in a web browser.

## Technologies

- HTML
- CSS
- JavaScript
- Browser Local Storage
